# Fontes TTF

Coloque aqui arquivos `.ttf` do Inter. Esta versão aceita os nomes do Google Fonts:

- `Inter_18pt-Regular.ttf`
- `Inter_18pt-Bold.ttf`
- `Inter_18pt-Black.ttf`

Também aceita `Inter_24pt-*`, `Inter_28pt-*` e os nomes simplificados `Inter-Regular.ttf`, `Inter-Bold.ttf`, `Inter-Black.ttf`.

Não use `.woff2`.
